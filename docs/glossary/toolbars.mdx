# Toolbars

## Joint Toolbar

<DocImage
  src={'/img/glossary/joint-toolbar.png'}
  alt="joint toolbar"
  maxWidth="24rem"
  border={true}
/>

| Icon                                             | Name                      | Description                                                                                                        |
| ------------------------------------------------ | ------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| ![](/img/glossary/ground-joint.png)              | Ground                    | Fixes the joint so it won’t move from its current position during motion.                                          |
| ![](/img/glossary/regular-welded-joint.png)      | Regular/Welded Joint      | Frees/Welds the joint depending on its current type. A welded joint provides a rigid connection between two links. |
| ![](/img/glossary/show-hide-curve.png)           | Show/Hide Curve           | Shows/hides the motion curve of the selected joint depending on its current state.                                 |
| ![](/img/glossary/show-hide-velocity-arrows.png) | Show/Hide Velocity Arrows | Shows/hides velocity arrows for the selected joint at each instant depending on its current state.                 |
| ![](/img/glossary/change-curve-color.png)        | Change Curve Color        | Opens a color menu for you to choose a color for the motion curve. Helps when dealing with many curves.            |
| ![](/img/glossary/lock-unlock.png)               | Lock/Unlock Joint         | Locks/unlocks the joint depending on its current state. If locked the coordinates of the joint are fixed.          |
| ![](/img/glossary/add-rotary-actuator.png)       | Add Rotary Actuator       | Adds a rotary actuator to the selected joint.                                                                      |
| ![](/img/glossary/add-linear-actuator.png)       | Add Linear Actuator       | Adds a linear actuator to the selected joint.                                                                      |

Click the three dots to open up the extra fields to manipulate the joint position: x and y.

## Link Toolbar

<DocImage
  src={'/img/glossary/link-toolbar.png'}
  alt="link toolbar"
  maxWidth="24rem"
  border={true}
/>

| Icon                                      | Name               | Description                                                                                                                                      |
| ----------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| ![](/img/glossary/ground-link.png)        | Ground             | Fixes the link to its current position so it won’t move from it.                                                                                 |
| ![](/img/glossary/change-link-color.png)  | Change Color       | Opens a color menu for you to choose a color for the link from. Helps when dealing with many links.                                              |
| ![](/img/glossary/clear-custom-shape.png) | Clear Custom Shape | Clears the body, excluding the link part, if it is joined with a shape. This results in a custom shape and a regular link.                       |
| ![](/img/glossary/duplicate.png)          | Duplicate          | Duplicates the link in its shape, color, and size. This includes if the link is joined via union with a shape.                                   |
| ![](/img/glossary/show-hide.png)          | Show/Hide          | Shows/Hides the link from view, making it invisible with only an outline of it and its joints showing. Converts to “show” if the link is hidden. |
| ![](/img/glossary/link-trace.png)         | Link Trace         | Shows the traces of the link for valid the simulation.                                                                                           |

Click the three dots to open up the extra fields to turn on link trace using the slider.

## Actuator Toolbar

<DocImage
  src={'/img/glossary/actuator-toolbar.png'}
  alt="actuator toolbar"
  maxWidth="24rem"
  border={true}
/>

| Icon                                         | Name                | Description                                                                                                   |
| -------------------------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------- |
| ![](/img/glossary/reverse.png)               | Reverse             | Reverses the direction of rotation for the actuator from clockwise to counterclockwise and vice-versa.        |
| ![](/img/glossary/open-actuator-chart.png)   | Open Actuator Chart | Opens the actuator chart for the selected rotary actuator. Serves as a useful shortcut rather than the panel. |
| ![](/img/glossary/change-actuator-color.png) | Change Color        | Lets you change the color of the actuator by selecting from a color chart.                                    |
| ![](/img/glossary/swap-from-to.png)          | Swap From/To        | Swap which link is moving with respect to the other link.                                                     |

Click the three dots to open up the extra fields to manipulate the rotary actuator ranges: Min and Max.

## Shape Toolbar

<DocImage
  src={'/img/glossary/shape-toolbar.png'}
  alt="shape toolbar"
  maxWidth="24rem"
  border={true}
/>

| Icon                                        | Name                 | Description                                                                                                      |
| ------------------------------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------- |
| ![](/img/glossary/change-shape-color.png)   | Change Color         | Opens a color menu for you to choose a color for the shape from. Helps when dealing with many shapes or objects. |
| ![](/img/glossary/duplicate.png)            | Duplicate            | Makes a copy of the shape that is selected.                                                                      |
| ![](/img/glossary/bring-to-front.png)       | Bring to Front       | Brings the selected shape to the front increasing its number to the number of shapes on the screen.              |
| ![](/img/glossary/send-to-back.png)         | Send to Back         | Sends the selected shape to the back decreasing its number to 1.                                                 |
| ![](/img/glossary/reset-transformation.png) | Reset Transformation | Resets the shape's transformation so that the shape's geometry center is at origin.                              |
