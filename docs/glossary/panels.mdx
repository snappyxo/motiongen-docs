| Icon                                                      | Name              | Description                                                                                                                                                                                                                                                                                 |
| --------------------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![select](/img/glossary/select.png)                       | Select            | Choose an object (joint/link) to modify/delete/move. | ![add-slot](/img/glossary/add-slot.png)                   | Add Slot          | Lets you add a slot to a link by clicking on the link body to add a slot between two revolute joints that are closest to where you clicked.                                                                                                                                                 |
| ![draw-cylinder](/img/glossary/draw-cylinder.png)         | Draw Cylinder     | Lets you draw a cylinder with the function of a link that can collapse and expand throughout a motion. Follow the same steps as drawing a link.                                                                                                                                             |
| ![measure](/img/glossary/measure.png)                     | Measure           | Allows you to measure the length between two joints by clicking on the first joint and then the second joint. Clicking on the dimension shown allows you to edit them as well.                                                                                                              |

| ![merge](/img/glossary/merge.png)                                   | Merge                  | Merges the selected shape with a link drawn inside the shape to create a link. Use the Multi-Select option to select a shape and link to merge them. This option creates a bonafide link with arbitrary shape.         |
| ![union](/img/glossary/union.png)                                   | Union                  | Unites the selected shapes to create a new resulting shape.                                                                                                                                                            |
| ![difference](/img/glossary/difference.png)                         | Difference             | Subtracts one shape from another. The order of subtraction is determined by the shape number. Thus, the new shape is obtained by performing S_i - S_i+1. You can change the overlap to change the order of the shapes. |
| ![intersection](/img/glossary/intersection.png)                     | Intersection           | Crates a new shape, which is common to two shapes.                                                                                                                                                                     |

**Note**: Merge, Union, Difference, and Intersection can be performed only on a pair of shapes at a time. However, you can repeat the process.

## Transform Panel

<DocImage
  src={'/img/glossary/transform-panel.png'}
  alt="transform panel"
  maxWidth="14rem"
  border={true}
/>

| Icon                                                              | Name                  | Description                                                                                                           |
| ----------------------------------------------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------- |
| ![rotate-90-degrees-ccw](/img/glossary/rotate-90-degrees-ccw.png) | Rotate 90 Degrees CCW | Rotates the selected object(s) by 90 degrees in the counterclockwise direction about its designated geometric center. |
| ![rotate-90-degrees-cw](/img/glossary/rotate-90-degrees-cw.png)   | Rotate 90 Degrees CW  | Rotates the selected object(s) by 90 degrees in the clockwise direction about its designated geometric center.        |
| ![vertical-mirror](/img/glossary/vertical-mirror.png)             | Vertical Mirror       | Mirrors the selected object(s) across a horizontal line passing through its geometric center.                         |
| ![horizontal-mirror](/img/glossary/horizontal-mirror.png)         | Horizontal Mirror     | Mirrors the selected object(s) across a vertical line passing through its geometric center.                           |

**Transforming With Values**: The rest of the transform panel is unlocked by pressing the extras button. It lets you perform the same actions as the icons but with specific values or coordinates.

- Fx and Fy locate the local reference frame about which the transformations discussed next are performed.
- Tx and Ty are the specific values for translation in each direction about the local reference frame.
- Sx and Sy are the specific values for the scaling about the local reference frame.
- R is the specific amount of degrees you wish to rotate counterclockwise from the positive x-axis about the local reference frame.

## Joint Graph Panel

<DocImage
  src={'/img/glossary/joint-graph-panel.png'}
  alt="joint graph panel"
  border={true}
/>

The Joint Graph panel provides **Displacement**, **Linear Velocity**, and **Linear Acceleration** graphs of the selected joint. It displays data in **linear units** since it is representing a point. The mechanism will also be shown in the panel with the selected joint highlighted. The hidden extras show a table of all the data which can be downloaded as either a pdf or an excel file.

Note: The **Displacement** is the distance between the selected joint and the frame shown on the mechanism snapshot.
