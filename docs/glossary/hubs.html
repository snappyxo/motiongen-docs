Hubs

Editor Hub​

IconNameDescription
Reset ViewResets the view zoom to 0% and position to be centered at the origin.
UndoUndoes your last action such as removing the last drawn link.
RedoForwards to the next action. For instance if you undo a link you had drawn you can press redo and draw that link again.
DeleteDeletes everything on the screen if nothing is selected or selected item(s) if a selection is made.

Player Hub​

IconNameDescription
Play/PausePlays/pauses the animation of the mechanism along the selected options.
StopStops the animation and resets the mechanism’s position to the original one at the start of the animation.
Open Player SlidersLets you open an additional menu to control each of the animation.

Click the Open Player Sliders button opens an additional menu contains a list of silders, each row is shown as below:

IconNameDescription
Ground Link LabelIdentifies which mechanism you are controlling.
Reverse Animation DirectionAllows you to reverse the animation timer for this mechanism.
Select Positive Time AnimationIn order to show the complete curve of the mechanism, an animation may include negative and positive time represent forware and backward simulations. This button allows you to pick the positive anaimation time only.
Animation SwitchAllows you to turn off the animation for this mechanism.
