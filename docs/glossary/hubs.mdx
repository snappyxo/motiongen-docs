# Hubs

## Editor Hub

<DocImage
  src={'/img/glossary/editor-hub.png'}
  alt="editor-hub"
  maxWidth="24rem"
  border={true}
/>

| Icon                              | Name       | Description                                                                                                             |
| --------------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------- |
| ![](/img/glossary/reset-view.png) | Reset View | Resets the view zoom to 0% and position to be centered at the origin.                                                   |
| ![](/img/glossary/undo.png)       | Undo       | Undoes your last action such as removing the last drawn link.                                                           |
| ![](/img/glossary/redo.png)       | Redo       | Forwards to the next action. For instance if you undo a link you had drawn you can press redo and draw that link again. |
| ![](/img/glossary/delete.png)     | Delete     | Deletes everything on the screen if nothing is selected or selected item(s) if a selection is made.                     |

## Player Hub

<DocImage
  src={'/img/glossary/player-hub.png'}
  alt="player-hub"
  maxWidth="16rem"
  border={true}
/>

| Icon                                       | Name                | Description                                                                                                |
| ------------------------------------------ | ------------------- | ---------------------------------------------------------------------------------------------------------- |
| ![](/img/glossary/play.png)                | Play/Pause          | Plays/pauses the animation of the mechanism along the selected options.                                    |
| ![](/img/glossary/stop.png)                | Stop                | Stops the animation and resets the mechanism’s position to the original one at the start of the animation. |
| ![](/img/glossary/open-player-sliders.png) | Open Player Sliders | Lets you open an additional menu to control each of the animation.                                         |

Click the **Open Player Sliders** button opens an additional menu contains a list of silders, each row is shown as below:

<DocImage
  src={'/img/glossary/player-slider.png'}
  alt="player slider"
  maxWidth="24rem"
  border={true}
/>

| Icon                                                  | Name                           | Description                                                                                                                                                                                                             |
| ----------------------------------------------------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![](/img/glossary/ground-link-label.png)              | Ground Link Label              | Identifies which mechanism you are controlling.                                                                                                                                                                         |
| ![](/img/glossary/reverse-animation-direction.png)    | Reverse Animation Direction    | Allows you to reverse the animation timer for this mechanism.                                                                                                                                                           |
| ![](/img/glossary/select-positive-time-animation.png) | Select Positive Time Animation | In order to show the complete curve of the mechanism, an animation may include negative and positive time represent forware and backward simulations. This button allows you to pick the positive anaimation time only. |
| ![](/img/glossary/switch.png)                         | Animation Switch               | Allows you to turn off the animation for this mechanism.                                                                                                                                                                |
