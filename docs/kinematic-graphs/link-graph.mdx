# Link Graph

First create a crank-rocker mechanism as in [Making Your First Mechanism](../making-your-first-mechanism/understanding-mechanism-design#draw-a-four-bar-mechanism). Then continue as below.

Open the _Link Graph_ panel and select the coupler link of interest. The link graph highlights the selected link and shows the displacement, velocity, and acceleration of that link in angular units.

**The Crank-Rocker Mechanism - Coupler Link Graph**: Click on the three dots on the right side of this window to see the numerical data, which can be exported.
