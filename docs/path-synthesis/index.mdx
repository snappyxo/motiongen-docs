# Path Synthesis

So far you’ve learned how to model known mechanisms to produce a coupler curve but what if you want to reverse the process? That is, given a curve as a set of path points, how to generate mechanism design concepts to create that curve approximately?

MotionGen has a panel specifically designated to do so. Open the Path Synthesis panel from the File menu.

<DocImage
  src={'/img/path-synthesis/file-menu-panel.png'}
  alt="file menu panel"
/>

Next, you will see the following panel on your main interface.

<DocImage
  src={'/img/path-synthesis/path-synthesis-panel.png'}
  alt="path synthesis panel"
  maxWidth="32rem"
  caption="The Path Synthesis Panel"
/>

## Synthesis with a Path

By drawing a path via Draw Path and pressing Run you can synthesize numerous solutions for a mechanism that follows that path.

<DocAnimation
  src={'/video/path-synthesis/synthesis-with-a-path.mp4'}
  title="synthesis with a path"
  border={true}
/>

## Path Emphasis

While you can use Draw Path to synthesize mechanisms, you can also use the _Emphasize_ and _De-emphasize_ icons to control which part of the motion curve is important.
